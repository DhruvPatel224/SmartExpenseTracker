# Smart Expense Tracker

A full-stack Expense Tracker application that helps users manage their daily expenses efficiently. The application allows users to add, update, delete, and view expenses while providing a dashboard with expense statistics and recent transactions.

## Features

- Add new expenses
- View all expenses
- Update existing expenses
- Delete expenses
- Dashboard with:
  - Total Expenses
  - Total Transactions
  - Recent Expenses
- Categorize expenses
- Store data in MongoDB
- Responsive user interface

## Tech Stack

### Frontend
- HTML5
- CSS3
- Bootstrap 5
- JavaScript (Fetch API)

### Backend
- Java
- Spring Boot
- Spring Data MongoDB
- REST API

### Database
- MongoDB

## API Operations

- GET – Retrieve expenses
- POST – Add a new expense
- PUT – Update an expense
- DELETE – Remove an expense
